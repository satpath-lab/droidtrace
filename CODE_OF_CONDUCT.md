# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the work. If something
goes wrong, contact me privately through GitHub ([@satpath-lab](https://github.com/satpath-lab))
and I will handle it confidentially.
